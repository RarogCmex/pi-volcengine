# AGENTS.md

Расширение-провайдер Volcengine API Gateway для pi coding agent. Детали протокола, таблицы моделей и пользовательская документация — в [README.md](README.md); верифицированные факты о квирках шлюза — в шапке-комментарии `index.ts`. Читай их перед изменением каталога или хуков.

## Структура

- `index.ts` — всё расширение: каталог моделей, `createProvider`, хуки `before_provider_request` / `message_end`, команда `/volcengine`.
- `settings.ts` — JSON-стор настроек (`<agentDir>/volcengine-gateway.json`, где agentDir = `getAgentDir()` хоста: `$PI_CODING_AGENT_DIR` или `~/.pi/agent`).
- `test/` — офлайн-тесты (`node:test` через tsx).
- `research/` — непроверенные находки из доков провайдера (датированы). Это **не** источник фактов для каталога: значение попадает в `index.ts`/README только после живой пробы.

## Проверка

```bash
npm run check    # typecheck + офлайн-тесты — обязательно до зелени перед коммитом
```

## Правила

- Тесты строго офлайн. Живые запросы к шлюзу тратят кредиты подписки — E2E только по явной просьбе пользователя, командами из раздела «Разработка» README.
- Факты о шлюзе (лимиты, effort-значения, retention-матрица) проверены живыми пробами и датированы. Меняя каталог, обновляй и комментарий-шапку `index.ts`, и README — не вводи непроверенные значения.
- Node ≥ 22, ESM, strict TS без эмита; сборки нет — pi исполняет `.ts` напрямую.
